# Changelog

## [v1.2] - 2026-06-18

### Что нового

#### Windows

- Добавлено первое рабочее окно настроек **Layout Toolkit — Настройки**:
  - левая навигация по разделам;
  - текстовые страницы состояния и описания функций;
  - служебные кнопки для управления пользовательскими файлами;
  - разделы **Общее**, **Layout Fix**, **Live-режим**, **Горячие клавиши**, **Unicode Input**, **CapsLock Fix**, **Исключения**, **О программе**.

- Добавлен рабочий раздел **Горячие клавиши**:
  - отображение текущих хоткеев из `Documents\Layout Toolkit\hotkeys.ini`;
  - отображение дополнительных пользовательских хоткеев из секции `[Hotkeys]`;
  - кнопка **Открыть hotkeys.ini**;
  - кнопка **Перезагрузить хоткеи** без перезапуска Layout Toolkit;
  - кнопка **Сбросить стандартные** с восстановлением из `Assets\hotkeys.default.ini`.

- Добавлена поддержка пользовательского файла хоткеев:
  - `Documents\Layout Toolkit\hotkeys.ini` используется как основной пользовательский файл;
  - `Assets\hotkeys.default.ini` используется как заводской шаблон;
  - если пользовательский файл отсутствует, он создаётся автоматически;
  - если заводской файл недоступен, используется встроенный fallback стандартных хоткеев.

- Добавлена возможность подключать дополнительные пользовательские хоткеи через секцию `[Hotkeys]`.
  Это создаёт базовую основу для будущих пользовательских модулей и plug-in системы.

- Добавлен рабочий раздел **Исключения**:
  - отображение пользовательского `Documents\Layout Toolkit\exclude.txt`;
  - отображение заводского `Assets\exclude.default.txt`;
  - отображение количества загруженных записей;
  - кнопка **Открыть exclude.txt**;
  - кнопка **Перезагрузить** без перезапуска Layout Toolkit;
  - кнопка **Сбросить стандартные** с восстановлением заводского словаря.

- Добавлены GUI-настройки **Live-режима**:
  - включение и выключение live-режима из окна настроек;
  - настройка `DoubleSpaceMs`;
  - настройка показа расширенной подсказки при первом включении;
  - сохранение параметров в `Documents\Layout Toolkit\settings.ini`.

- Обновлено окно первого обучения:
  - теперь оно описывает не только базовые хоткеи, но всю систему Layout Toolkit;
  - добавлено описание Layout Fix, Live-режима, Unicode Input, CapsLock Fix, пользовательских файлов и Settings GUI;
  - хоткеи в тексте подтягиваются из текущих значений `hotkeys.ini`;
  - окно стало компактнее и использует прокручиваемую область текста.

- Добавлен **Unicode Input**:
  - ввод Unicode-символов по HEX-коду;
  - поддержка одиночного кода: `2014` → `—`;
  - поддержка нескольких кодов через пробел: `0060 2014 0060` → `` `—` ``;
  - поддержка слитного ввода блоками по 4 символа: `006020140060` → `` `—` ``;
  - хоткей открывает режим вставки символа в активное окно;
  - кнопка из Settings GUI открывает то же окно в режиме копирования результата в буфер обмена.

- Добавлен **CapsLock Fix**:
  - исправление регистра выделенного текста;
  - примеры:
    - `пРИВЕТ` → `Привет`;
    - `эТО ПРИМЕР` → `Это пример`;
    - `тАК. пРИМЕР` → `Так. Пример`;
    - `GitHUB` → `GitHub`;
    - `POWERSHELL` → `PowerShell`;
  - используется `exclude.txt` для восстановления канонического написания технических слов.

- Пользовательские настройки и словарь исключений перенесены в:
  - `Documents\Layout Toolkit\settings.ini`;
  - `Documents\Layout Toolkit\hotkeys.ini`;
  - `Documents\Layout Toolkit\exclude.txt`.

- Добавлена мягкая миграция старых пользовательских данных:
  - старый `settings.ini` из `%APPDATA%\LayoutToolkit`;
  - старый `exclude.txt` рядом со скриптом.

- В трей-меню добавлены и обновлены пункты:
  - **Настройки...**;
  - **Открыть папку Layout Toolkit**;
  - **Открыть exclude.txt**;
  - **Перезагрузить словарь исключений**.

- Двойной клик по иконке Layout Toolkit в трее теперь открывает окно настроек.

- Пункт live-режима в трее отображается как чекбокс.

### Исправлено

- Убраны захардкоженные хоткеи из текстов разделов настроек.
  Теперь GUI берёт отображаемые сочетания из текущих значений `hotkeys.ini`.

- Исправлено ложное срабатывание live-режима при очень быстром наборе текста.
  Теперь второй пробел считается двойным пробелом только если между двумя пробелами не было обычного ввода.

- Исправлено выключение live-режима:
  - при выключении реально останавливается `InputHook`;
  - пробел снова нормально доходит до игр и приложений.

- Улучшена логика словаря исключений:
  - `exclude.txt` хранит не только факт исключения, но и каноническое написание;
  - это позволяет восстанавливать правильный регистр: `pOWERSHELL` → `PowerShell`.

- Улучшена работа Settings GUI:
  - live-контролы показываются только в разделе **Live-режим**;
  - остальные разделы сохраняют нормальный размер текстовой области;
  - разделы настроек обновляют отображение после действий reload/reset.

- Улучшено окно обучения:
  - текст больше не растягивает окно за пределы экрана;
  - основной текст помещён в прокручиваемое поле;
  - убрано случайное выделение текста при открытии;
  - исправлено лишнее жирное начертание текста.

### Технические изменения

- Добавлена папка `Modules` для отдельных AHK-модулей.

- Добавлены модули:
  - `Modules\SettingsGui.ahk`;
  - `Modules\UnicodeInput.ahk`;
  - `Modules\CapsLockFix.ahk`.

- Добавлена карта хоткеев `g_Hotkeys` и единая логика получения хоткеев через `GetHotkey()`.

- Добавлены функции обслуживания хоткеев:
  - `EnsureHotkeysFile()`;
  - `LoadHotkeys()`;
  - `RegisterHotkeys()`;
  - `RegisterOneHotkey()`;
  - `OpenHotkeysFile()`;
  - `ReloadHotkeys()`;
  - `RestoreDefaultHotkeys()`;
  - `GetDefaultHotkeysText()`.

- Добавлены функции обслуживания словаря исключений:
  - `EnsureExcludeFile()`;
  - `LoadExcludeWords()`;
  - `OpenExcludeFile()`;
  - `ReloadExcludeWords()`;
  - `RestoreDefaultExcludeWords()`;
  - `GetDefaultExcludeText()`.

- Добавлена базовая связка GUI-действий через `SettingsGui_RunAction()` для:
  - открытия пользовательских файлов;
  - перезагрузки пользовательских данных;
  - сброса пользовательских данных до стандартных;
  - открытия Unicode Input в режиме копирования;
  - сохранения настроек Live-режима.

- Добавлены функции обслуживания Live-настроек:
  - `NormalizeLiveDoubleSpaceMs()`;
  - `ReadLiveDoubleSpaceMs()`;
  - `SetLiveMode()`;
  - `ShowLiveFirstToggleHint()`.

- Unicode Input переведён на общую функцию с режимами:
  - `insert`;
  - `clipboard`.

- Settings GUI перестал быть read-only заготовкой.
  Теперь он выполняет реальные действия управления пользовательскими файлами и настройками Layout Toolkit.

## [v1.1] - 2026-05-22

### Что нового

#### Windows

- Добавлен **словарь исключений** (`exclude.txt`).  
  Скрипт теперь пропускает технические слова, пути, команды и домены (`USB`, `PowerShell`, `GitHub`, `C:\`, `https://`, `.com`, `.ru` и другие). Пользователь может самостоятельно добавлять свои исключения.

- В трей-меню добавлены новые пункты:
  - **Открыть exclude.txt** — быстро открыть файл для редактирования.
  - **Перезагрузить словарь исключений** — применить изменения без перезапуска скрипта.
  - **Показывать уведомления** и **Звук уведомлений** — гибкое управление уведомлениями.

- В окно первого обучения добавлено напоминание о словаре исключений.

- Улучшена **стабильность live-режима**. Теперь он лучше справляется с быстрым вводом и повторными двойными пробелами.

- Улучшена работа с буфером обмена — снижена вероятность вставки старого содержимого.

- Добавлена **кастомная иконка** (`icon.ico`). Теперь она используется в трее и в ярлыке автозагрузки.

- Обновлён **Startup Manager** — теперь создаёт ярлык автозагрузки с кастомной иконкой.

#### Linux Wayland

- Добавлен общий Python-модуль `layout_core.py`.  
  Оба скрипта (`convert-layout` и `convert-layout-majority`) теперь используют единую логику.

- Добавлена поддержка `exclude.txt` — исключения работают и на Linux.

### Исправлено

- Улучшена стабильность live-режима при быстром повторном запуске конвертации.
- Исправлена логика `g_Suppress` при отправке пробелов.
- Улучшена обработка быстрых live-операций: добавлена логика `g_LiveBusy` и pending-буфера.
- Улучшена работа с буфером обмена: используется более безопасное ожидание через `ClipWait`.

### Технические изменения

- Windows-версия получила поддержку пользовательского словаря исключений, настроек уведомлений и кастомной иконки.
- Linux-версия получила общий модуль `layout_core.py` и поддержку `exclude.txt`.
- Улучшена работа с буфером обмена в быстрых сценариях.
- Уменьшено дублирование логики в Linux-скриптах.

## [v1.0] - 2026-05-21

### Первый релиз

#### Windows

- Добавлен единый AHK v2-скрипт `Layout_Toolkit_RU_EN.ahk`.

- Добавлены основные горячие клавиши:
  - **Win + F12** — полная конвертация выделенного текста в противоположную раскладку.
  - **Win + F11** — конвертация смешанного текста по языку большинства.
  - **Win + F10** — включение и выключение live-режима.

- Добавлен **live-режим**:
  - двойной пробел запускает live-конвертацию текущего набранного фрагмента;
  - режим рассчитан на быстрое исправление текста, набранного в неправильной раскладке.

- Добавлено окно первого обучения с описанием основных функций.

- Добавлен `Run_Layout_Toolkit.cmd`:
  - проверяет наличие AutoHotkey v2;
  - запускает основной AHK-скрипт;
  - при отсутствии AutoHotkey открывает официальный сайт.

- Добавлен `Startup_Manager.cmd`:
  - добавляет скрипт в автозагрузку;
  - удаляет скрипт из автозагрузки;
  - создаёт ярлык в папке автозагрузки пользователя.

#### Linux Wayland

- Добавлены первые Linux-скрипты:
  - `convert-layout`;
  - `convert-layout-majority`.

- Реализована конвертация текста через буфер обмена Wayland.
